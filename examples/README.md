# Examples

This directory contains synthetic outputs generated by the reference simulators and validation runners.

These files are included to demonstrate output schema and reproducibility. They are not external empirical validation.

## Subdirectories

- `minimal/`: minimal simulator event log and summary.
- `predictive/`: prediction-record simulator output.
- `validation/`: condition-grid and prediction-lift summaries.
- `trainable_validation/`: held-out trainable predictor validation outputs.
- `smoke/`: generated locally by `make smoke`; ignored by git.
