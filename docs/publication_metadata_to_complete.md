# Publication Metadata to Complete

Before publishing the repository, uploading a preprint, or submitting to a venue, complete the following items.

## Author metadata

- Author name or author list
- Affiliations
- Corresponding author email
- ORCID identifiers, if available
- Contributor roles, if desired

## Manuscript metadata

- Final title confirmation
- Abstract approval
- Keywords
- Short title, if needed
- Target venue or preprint server
- Preferred citation format

## Statements

- Acknowledgements
- Funding statement
- Competing interests statement
- Data availability statement
- Code availability statement
- Ethics statement
- AI assistance statement, if required by the selected venue

## Licensing

Current repository license status: pending.

Decide whether to use:

- CC BY 4.0 for the manuscript and documentation,
- MIT or Apache-2.0 for code,
- another license structure,
- or a private/all-rights-reserved release.

## Repository publication

- Replace placeholder GitHub URL in `CITATION.cff`.
- Replace placeholder author metadata in `CITATION.cff` and `AUTHORS.md`.
- Update `LICENSE.md` after license decision.
- Add maintainer contact in `SECURITY.md`.
