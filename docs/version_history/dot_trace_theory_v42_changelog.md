# Dot-Trace Theory v0.42 Changelog

## Focus of this revision

Version 0.42 performs a strategic readiness and integration pass. The goal was not to add another technical mechanism, but to clarify how the mature long-form theory should be read, used, and extended without weakening its academic claim discipline.

## Main manuscript changes

1. Added a new section, **Discussion: Research Uses and Integration**.
   - Clarifies five research uses of Dot-Trace Theory: diagnostic, comparative, generative, measurement-oriented, and governance-oriented.
   - Explains the evidentiary standard appropriate to each use.
   - Adds a new table mapping theory use to central question and appropriate evidence/output.

2. Strengthened the transition from cross-section claim discipline into boundary conditions.
   - The paper now more clearly distinguishes formal, empirical, implementation, validation, and governance claims.
   - The added discussion section clarifies how the layered architecture fits together.

3. Expanded the conclusion with a final methodological synthesis.
   - Emphasizes that social memory should not be treated only as private cognition or only as graph structure.
   - Frames memory as distributed across agents, artifacts, institutions, platforms, and communication paths.

4. Preserved the mature academic tone introduced in previous versions.
   - No development-stage language was added.
   - No roadmap-style “next step” phrasing appears in the manuscript body.
