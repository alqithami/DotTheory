# Dot-Trace Theory Working Paper v0.18 - Changelog

This revision prioritizes manuscript quality before beginning an external empirical study.

## Main paper-level improvements

- Replaced the version-specific abstract with a more journal-style abstract.
- Added a new `Contribution, Scope, and Reader's Guide` section.
- Added an explicit research question.
- Added an eight-part contribution statement.
- Added scope conditions and non-claims to prevent overclaiming.
- Added a new `Claim Discipline and Publication Strategy` section.
- Added a claim hierarchy separating conceptual, representational, dynamic, predictive, and empirical claims.
- Added a core testable thesis using conditional mutual information.
- Added a minimum publishable core to guide future paper submission.
- Added a reviewer-facing risk register.
- Added a pre-empirical development priority and a minimal extraction rule for candidate dots.
- Added an assumptions and proof-obligations layer.
- Added a theorem dependency map.
- Added a new `Falsifiability and Failure Modes` section.
- Added an `Ethical and Governance Considerations` section.
- Added a version consolidation note and strengthened the article-level novelty discipline.

## Technical improvement

- Added guarded PDF compression settings so the compiled PDF can be inspected by standard PDF tools while remaining Overleaf-ready under pdfLaTeX.
