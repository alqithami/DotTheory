# Dot-Trace Theory v0.19 Changelog

## Purpose of this revision

Version 0.19 addresses a structural weakness in v0.18: the research roadmap was too short relative to the scope of the project. The revision keeps the project in pre-empirical foundation-building mode and expands Section 27 into an executable research programme.

## Main changes

1. Replaced the brief four-phase roadmap with a detailed roadmap section.
2. Added roadmap satisfaction criteria: conceptual, formal, mechanistic, operational, and falsifiability checks.
3. Added a current-status table covering ontology, representation theory, consensus, fragmentation, temporal sequencing, institutional memory, topology and reputation, correction, mutation and compression, identifiability, algorithmic implementation, validation, social capital, ethics, and publication readiness.
4. Added twelve work packages: notation freeze, core representation theory, dynamic theorem integration, social capital and centroid module, measurement and coding protocol, identifiability, simulator hardening, synthetic benchmarks, governance, empirical pilot design, submission article compression, and technical report preparation.
5. Added Phase 0 for foundation stabilization before empirical work.
6. Added a canonical state-hierarchy roadmap distinguishing reduced states, core dot fields, augmented dot fields, and implementation states.
7. Added roadmap tasks for strengthening the representation theorem family and mixed-mechanism dynamics.
8. Added a social-capital roadmap task treating social capital as a derived value functional.
9. Added operationalization tasks: dot extraction rulebook, identity levels, and measurement table.
10. Added theorem-mapped benchmark requirements and stress tests.
11. Added empirical-readiness requirements without starting the empirical study.
12. Added governance requirements and publication architecture.
13. Added dependency chains for the full programme, social capital, and correction.
14. Added a definition of foundation completeness.
15. Replaced the v0.18 consolidation note with a v0.19 roadmap completion note.

## Strategic implication

The next recommended manuscript step is a notation and state-hierarchy audit, followed by a formal upgrade of the dot-centroid and dot-mediated social-capital sections. Empirical work should still wait until the foundation version is complete.
