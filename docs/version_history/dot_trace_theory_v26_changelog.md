# Dot-Trace Theory Working Paper v0.26 Changelog

## Revision focus

Version 0.26 is a **worked-examples and literature-consolidation pass**. The goal was to make the theory easier to read as an academic manuscript by showing how the formal apparatus operates in concrete cases and by tightening the positioning against adjacent literatures.

## Main additions

1. **Expanded related-work section**
   - Reworked the literature review into a clearer map across:
     - dynamic graph learning and event-based network models,
     - agent memory and generative agents,
     - graph-based agent memory,
     - LLM-agent societies and synthetic social systems,
     - collective memory and social-network topology,
     - consensus and social influence,
     - social capital, weak ties, and brokerage,
     - organizational and institutional memory,
     - identifiability, causal inference, and validation.
   - Added a consolidated positioning table distinguishing what each adjacent literature contributes and what Dot-Trace Theory adds.

2. **Added worked examples and boundary cases**
   - Added a new section: *Worked Examples and Boundary Cases*.
   - Included five concrete instantiations plus one boundary case:
     - two-agent trust repair after betrayal,
     - organizational incident memory,
     - bridge-mediated collective memory,
     - public accusation, correction, and residual harm,
     - LLM-agent workspace with public and private memory,
     - memoryless boundary case where Dot-Trace Theory adds little.

3. **Mapped examples to mechanisms and theorem signatures**
   - Added a worked-example synthesis table linking each example to:
     - key dot-field objects,
     - active mechanisms,
     - relevant theorem signatures.

4. **Clarified dot, centroid, and social capital relationships**
   - Reinforced that a dot is not a centroid by definition.
   - Clarified that social capital is not a dot; it is a derived advantage or liability generated through dot access, trust, reputation, brokerage, archives, correction, and semantic control.

5. **Added and organized references**
   - Added references for digital collective memory, organizational memory, organizational learning, boundary objects, social influence, and LLM-agent social simulation.
   - Reordered the references alphabetically for more professional academic presentation.

6. **Roadmap update**
   - Updated the research roadmap to mark worked examples and literature consolidation as substantially satisfied at the foundation level.
   - Updated the next foundation task to appendix organization, diagram improvement, and simulator calibration.

7. **Version note update**
   - Added the appendix note for Version 0.26 explaining the worked-examples and literature-consolidation revision.
